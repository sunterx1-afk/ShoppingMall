## 👤 본인 담당 기능

### 🏠 메인 페이지

**NEW ARRIVALS — 최신 등록순 상품 노출**
- 관리자가 등록한 상품 중 최신순 상위 8개 상품 메인에 자동 노출 (Top-N 쿼리 최적화)
- 관리자 페이지 등록 즉시 메인 페이지 실시간 반영

**WEEKLY BEST — 좋아요 순 상품 노출**
- 사용자 좋아요(LIKE) 수 기준 상위 8개 인기 상품 자동 정렬·노출
- 실시간 좋아요 반영에 따른 순위 자동 갱신

---

### 🗂 상품 CRUD & 데이터 무결성

- **상품 전체 CRUD 구현** (MyBatis 기반 등록·수정·삭제·조회)
- **소프트 삭제(Soft Delete) 적용**
  - 주문/장바구니 이력과의 데이터 정합성 보존을 위해 물리 삭제 대신 상태 플래그 변경 방식 채택
  - 판매 중지 처리 시 사용자 화면 및 메인 목록에서 자동 제외
- **장바구니/주문 유효성 검증**
  - 장바구니 담김 상태에서 품절(SOLD OUT) 또는 판매 중지로 전환된 상품의 결제 진입 원천 차단

---

### 🔧 관리자 페이지

- 카테고리·브랜드·가격·재고·이미지 입력 및 상품 등록
- 카테고리별 상품 목록 조회, 수정·삭제 기능 제공
- 대표/상세 이미지 교체 기능을 포함한 상품 정보 수정
- **판매 중지 상품 관리 센터**
  - 소프트 삭제된 판매 중지 상품 전용 목록 조회
  - 필요 시 원복시킬 수 있는 '상품 복구' 기능 구현
