## 👤 본인 담당 기능

### 🏠 메인 페이지

**NEW ARRIVALS — 최신 등록순 상품 노출**
- 관리자가 등록한 상품을 최신순으로 8개 메인에 자동 노출
- 관리자 페이지 등록 즉시 메인에 반영

**WEEKLY BEST — 좋아요 순 상품 노출**
- 사용자 좋아요 수 기준 상위 8개 상품 자동 정렬·노출
- 실시간 좋아요 반영으로 순위 자동 갱신

---

### 🗂 상품 CRUD

- 상품 등록·수정·삭제·조회 기능 전반 구현
- 관리자 페이지와 메인 페이지 연동하여 데이터 실시간 반영
- 상품 판매 중지 처리 시 목록에서 자동 제외

---

### 🔧 관리자 페이지

- 카테고리·브랜드·가격·재고·이미지 입력 후 상품 등록
- 카테고리별 상품 목록 조회, 수정·삭제 버튼 제공
- 이미지 교체 기능 포함한 상품 수정
- 판매 중지 상품 별도 목록 관리 및 복구 기능
